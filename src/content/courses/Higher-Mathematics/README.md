# 高等数学 (Higher Mathematics)

欢迎查阅**软件工程**与**计算机科学与技术**专业核心学科基础课 —— 《高等数学》知识库。

## 课程导引与大纲结构

高等数学是工科学科体系中最基础、最重要的数学基石之一，为后续的《数据结构与算法》、《计算机网络》、《数字图像处理》及各类系统建模提供严谨的数理支撑。

### 核心知识模块

1. **函数、极限与连续性**
   - 数列极限与函数极限的定义及性质（$\varepsilon\text{-}\delta$ 语言）
   - 两个重要极限：
     $$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
     $$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e$$
   - 闭区间上连续函数的性质（介值定理、零点定理、最大最小值定理）

2. **导数与微分**
   - 导数的几何意义与物理意义
   - 复合函数、反函数与隐函数求导法则
   - 高阶导数与莱布尼茨公式

3. **微分中值定理与导数应用**
   - 罗尔定理、拉格朗日中值定理、柯西中值定理
   - 洛必达法则（L'Hôpital's rule）
   - 泰勒公式（Taylor's theorem）与麦克劳林展开式：
     $$f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(x_0)}{k!} (x - x_0)^k + R_n(x)$$

4. **不定积分与定积分**
   - 第一换元积分法（凑微分法）与第二换元积分法
   - 分部积分法：
     $$\int u \, \mathrm{d}v = uv - \int v \, \mathrm{d}u$$
   - 微积分基本定理（牛顿-莱布尼茨公式）：
     $$\int_{a}^{b} f(x) \, \mathrm{d}x = F(b) - F(a)$$

5. **常微分方程初步**
   - 一阶可分离变量微分方程
   - 一阶线性微分方程的常数变易法
   - 二阶常系数齐次与非齐次线性微分方程
